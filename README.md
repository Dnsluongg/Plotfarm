# Plot Farm Prototype

A frontend-only React + Vite prototype based on the Plot Farm specification.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Included

- My Farm dashboard
- Plot cards and growth progress
- Rent plot
- Plant crop
- Water / fertilize
- Harvest mature crops
- Inventory
- Farming history
- Manage Farmer / automation toggle
- Notifications
- Responsive layout

This is a prototype: authentication, database persistence, real-time timers, payments, and backend APIs are not implemented yet.
